# .NET support
CodeGlass also has support for .NET applications. When creating a [new application](../../views/general/application-list#add-application), you can select .NET DLL or .NET Executable.

Keep in mind that the .NET integration is still considered experimental and might still contain a few bugs. If you find any, please [report](/contact) them to us. This experimental support also means that the docs are not yet fully updated to also match what is compatible with the .NET integration and what is Julia specific.

:::info
If you need any other type of .NET application, like IIS Express or UWP, please [contact](/contact) us.
:::
