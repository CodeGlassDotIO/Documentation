# Getting Started

There are a few things you need to do to get your first application running with CodeGlass. This page provides a complete step-by-step guide. If you experience any issues while setting up CodeGlass, feel free to [reach out](/contact) at any time.

## 1. Installation

The steps for setting up CodeGlass differ depending on your operating system. You can find the guide for each operating system here: [Linux](getting-started/linux), [macOS](getting-started/macos), and [Windows](getting-started/windows).

## 2. Log In / Register

After getting CodeGlass up and running on your system, you should see the [log in](./views/general/login) page. If you already have an account, you can simply log in here. Otherwise, you can go to the [register page](./views/general/register) and create a trial account. Once you have registered, your password will be sent to the email address you provided, and you can use it to log in.

## 3. Create Your First Application

To create your first application using CodeGlass, follow this [*How To*](./how-to/basic/create-application).

## 4. Start Using CodeGlass

Once you have started your first instance, you can start investigating your application. There are a couple of [basic](./category/basic) and [advanced](./category/advanced) *How To* guides to help you get the most out of CodeGlass.
